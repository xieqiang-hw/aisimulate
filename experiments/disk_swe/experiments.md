# SWE-chat 实验记录

SWE-chat Claude Code 主会话，上下文上限 128K，每组 174,438 条请求。

联合 SLA：TTFT ≤ 1 秒，且单条请求平均 TPOT ≤ 30 ms。表中 TPOT 为报告的请求平均值；G1/G2/G3 复用率均为首次准入的对应复用 token 总数／输入 token 总数，总复用率为三层之和。SSD 累计读包含重复恢复，不能直接等同首次准入复用量。GB/TB 使用十进制。

配置：H200 SXM、1P1D，P/D 各 Attention TP8／DP1，MoE TP8／EP1；P、D 使用独立本地 G2 池，D 侧 DRAM 约 256 GB；P 侧本地 G3 约 56 TB。默认 SSD 读写各 8 GB/s／TP 分片，H2D 为 25 GB/s／TP 分片。每个 KV 块含 64 token。 单块为 3,853,824 字节／TP 分片（TP8 整实例为 30,830,592 字节），旧版传输估算采用 5,750,784 字节／分片。

本轮关闭逐轮调度观测，保留逐请求报告与汇总指标。

本轮在 KV 字节数修正后重跑 48 组场景 1 实验，每批最多 4 组并行，每组进程树内存预算 4 GB。配置中的块数保持不变。墙钟耗时受并发及记录开关影响，不用于引擎性能对比。
