# SWE-chat 新数据集实验记录

使用 verified interleave 版 SWE-chat Claude Code 主会话，GLM-5.2 tokenizer，上下文上限 128K，每组 607,190 条请求。

联合 SLA：TTFT ≤ 1 秒，且单条请求平均 TPOT ≤ 30 ms。表中 TPOT 为报告的请求平均值；G1/G2/G3 复用率均为首次准入的对应复用 token 总数／输入 token 总数，总复用率为三层之和。SSD 累计读包含重复恢复，不能直接等同首次准入复用量。GB/TB 使用十进制。

配置：H200 SXM、1P1D，P/D 各 Attention TP8／DP1，MoE TP8／EP1；P、D 使用独立本地 G2 池，D 侧 DRAM 约 256 GB；P 侧本地 G3 约 56 TB。默认 SSD 读写各 8 GB/s／TP 分片，H2D 为 25 GB/s／TP 分片。每个 KV 块含 64 token。 单块为 3,853,824 字节／TP 分片（TP8 整实例为 30,830,592 字节）。

扣排队后的 TTFT 逐请求减去 P 首次准入前的调度等待后再汇总，保留 KV 恢复和后续耗时。联合 SLA 仍按标准 TTFT 计算。

本轮按 24 组串行回放，每组进程树内存预算 21 GB。保留汇总和逐请求报告。
