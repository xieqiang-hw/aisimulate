统计口径

TTFT 使用请求到达至首 token 的时间；“扣排队后 TTFT”只扣除 P 首次准入前调度等待，仍保留 KV 恢复等待、后续 chunk 等待、PD 交接及 D 侧等待。它不是移除系统所有排队后的重新仿真结果。

TPOT 是每条请求的平均输出 token 间隔，来自报告的 itl_ms 字段；输出不足两个 token 的请求无 TPOT，单独计为缺失，不填成 0。它不是最大单次 token 间隔。

直方图采用等宽分箱。切换 P95 / P99 只隐藏右侧长尾，页面明确列出隐藏数量；纵轴百分比仍以全部有效请求数为分母，不将截尾后的主体重新归一为 100%。0 等待是有效值，计入第一箱。

分布覆盖整场请求，不限于主要负载阶段；不同配置可比较分布形状，但独立分箱的区间边界可能不同。分位数采用排序后最近秩：索引 round((N−1)×p)。失败配置不展示部分运行数据。
