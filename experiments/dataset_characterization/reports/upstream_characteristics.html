原始数据集画像 · FreeInference × SWE-chat

统计本地上游发布表，保留原模型、原 token 字段及原序列。FreeInference 按请求计轮，SWE-chat 按带原生响应 ID 的主会话模型响应计轮。蓝绿色代表 FreeInference，橙色代表 SWE-chat。

FreeInference 输入为发布表的 o200k 角色 token 总和，输出为 provider completion tokens。SWE-chat 总输入长度仅统计 Claude Code 中使用 Claude 模型且有有效 usage 的响应。总输入等于同一条 usage 记录的 input_tokens、cache_read_input_tokens 和 cache_creation_input_tokens 之和。同一响应有多个 usage 记录时取最大总输入。SWE-chat 输出仍统计所有客户端中有有效 output_tokens 的响应。

SWE-chat 扫描主会话事件表中的全部客户端和模型。模型响应需要同时具备 session_id、原生 response_id 和事件顺序，再按会话和响应 ID 合并内容块。有至少一个符合条件的响应才计入模型响应会话数。长度统计另按有效 usage 取样，只在另一项 usage 或缓存字段证明 usage 存在时保留零值。
