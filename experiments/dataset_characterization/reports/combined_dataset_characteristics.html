会话总览按「周次 + 会话 ID」为 FreeInference 去重，按「会话 ID」为 SWE-chat 去重。一次用户提示可以触发多次模型调用，用户交互轮数另列。

FreeInference 原始表一行是一次模型请求，覆盖 16 周。SWE-chat 原始主会话表按 session_id + response_id 归并模型响应，要求原生响应 ID 和有效事件顺序。

FreeInference 输入为 o200k 角色 token 总量，输出为源模型 completion tokens。SWE-chat 原始总输入只覆盖有有效 usage 的 Claude Code / Claude 响应，含缓存读写 token；原始输出覆盖所有有有效输出 usage 的已识别响应。

实验输入统计采用两个实际使用的原速基础包。FreeInference 的会话轮数图按「周次 + 来源模型 + 会话 ID」分组（13,043 组）。

FreeInference 沿用源数据的 o200k 输入 token 数和 completion tokens。SWE-chat 对重建的历史和输出用 GLM tokenizer 重新分词。

各长度指标按有效样本计算，分位数采用 nearest-rank。

实验输入的筛选与转换

FreeInference

原始 1,222,199 条请求中，排除 4,727 条零输出请求和 552,057 条输入加输出超过 131,072 token 的请求，保留 665,415 条。统一映射到 zai-org/GLM-5.2-FP8，长度沿用来源计数。

SWE-chat

只重建有原始日志的 Claude Code 主会话。交错响应通过 requestId 和工具调用关联核验，歧义调用舍弃，遇到明确的独立上下文起点才恢复。从 11,334 个会话提取 709,396 次调用，其中 102,111 条超过 131,072 token，95 条缺少初始历史。最终以 zai-org/GLM-5.2-FP8 tokenizer 生成 607,190 条实验输入请求。

客户端、服务与来源模型

FreeInference 上游提供匿名服务标签；SWE-chat 用会话索引的客户端标签。来源模型保留原标签，包括「未知」。同一会话使用多个模型时可覆盖多个模型类别。

原始数据 · FreeInference：每个上游周内会话按 step 顺序统计 step_trigger=user 的请求。工具触发的请求归入最近一次用户输入。

原始数据 · SWE-chat：按上游 sessions 索引统计每个会话的 user_prompt 事件。每条人工提示计一轮，工具回传不计。

实验输入 · FreeInference：通过周次和原表行号对齐实验输入请求。只计至少关联一条保留请求的用户输入，同一用户输入关联多次调用只计一轮。0 表示匹配到调用但原记录没有可归属的用户输入。

实验输入 · SWE-chat：以 session_id 和 response_id 匹配实验输入调用与主会话事件，把匹配的调用归入前一条 user_prompt。同一提示只计一次。仅覆盖至少匹配一条调用的实验输入会话，0 表示已有匹配调用但找不到更早的提示。
